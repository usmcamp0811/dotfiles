# Subdirectories

* [adguard](adguard/README.md) - A comprehensive NixOS module for AdGuard Home - a network-wide ad blocker and privacy protection tool.
* [dnscrypt-proxy](dnscrypt-proxy/README.md) - This NixOS module provides privacy-preserving DNS resolution using dnscrypt-proxy with Oblivious DNS over HTTPS (ODoH).
* [firefly-plaid-connector](firefly-plaid-connector/README.md) - This guide will walk you through setting up the Plaid Connector 2 for Firefly III, allowing you to link your financial accounts to Firefly III for easy transaction tracking.
* [glusterfs](glusterfs/README.md) - This module configures a GlusterFS server using a declarative interface under campground.services.glusterfs.
* [hister](hister/README.md) - A NixOS module for Hister - Your own personal search engine for indexing and searching your browsing history and local files.
* [home-assistant](home-assistant/README.md) - Runs the NixOS Home Assistant Core service, using fmf's usual enable/options wrapper and optional Vault Agent AppRole sidecar.
* [immich](immich/README.md) - Wraps the upstream services.immich NixOS module with Postgres (via fmf.services.postgresql), Redis and machine learning defaults.
* [jitsi](jitsi/) - A comprehensive NixOS module for deploying Jitsi Meet video conferencing with Vault-based secret management.
* [k3s](k3s/README.md) - NixOS module for deploying and managing K3s clusters with GitOps support.
* [ldap-client](ldap-client/README.md) - This module provides LDAP client support for NixOS.
* [llama-cpp](llama-cpp/README.md) - The llama.cpp service module with an on-demand model router, and the client module that gives OpenCode its provider and credential.
* [niks3](niks3/README.md) - The niks3 binary cache: server module, auto-upload hook, client substituter setup and access model.
* [nostalgex](nostalgex/README.md) - Serves the Nostalgex web tuner, a retro cable-TV channel guide for a Plex, Jellyfin or Emby library, with Nginx.
* [openvpn](openvpn/README.md) - This README provides a comprehensive guide on how to set up an OpenVPN server on NixOS, with certificates generated and managed by HashiCorp Vault.
* [paperless](paperless/README.md) - The NixOS Paperless module facilitates the deployment and management of the Paperless document management system on your NixOS setup using a flake.
* [postgresql](postgresql/README.md) - This is a custom NixOS module designed to manage PostgreSQL databases.
* [user-secrets](user-secrets/README.md) - The User Secrets Service is a NixOS module designed to securely fetch and manage user-specific secrets from HashiCorp's Vault.
* [vault](vault/README.md) - This module simplifies the configuration and management of HashiCorp Vault on NixOS.
* [vault-agent](vault-agent/README.md) - This guide will walk you through the process of securely providing secrets to a NixOS system using Hashicorp Vault.
