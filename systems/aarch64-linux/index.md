# Subdirectories

* [krulak](krulak/README.md) - An Orange Pi 6 Plus reference configuration with encrypted Btrfs, an ephemeral root, and key-only SSH, named for Marine Lieutenant General Victor Krulak.
* [pikvm](pikvm/README.md) - A Raspberry Pi 4 PiKVM reference configuration that uses nixos-raspberrypi's cached kernel and cache, so a first build fetches the kernel instead of compiling it.
